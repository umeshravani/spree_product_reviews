# Compatibility Matrix

| Component | Supported Versions | Notes |
|---|---|---|
| **Spree Commerce** | `6.0.0`, `6.0.1+` | Built and verified on Spree 6.0.1. (For Spree 5.x, use legacy branch `spree-5`). |
| **Ruby** | `3.3.x`, `3.4.x`, `4.0.x` | Verified on Ruby 3.4.7 and Ruby 4.0.9 with Rails 8.1.4 and Spree 6.0.1. |
| **Rails** | `7.2.x`, `8.0.x`, `8.1.x` | Compatible with Active Support, Active Storage, and Solid Queue. |
| **PostgreSQL** | `14+`, `15`, `16`, `17` | Tested on PostgreSQL 16. |
| **MySQL / MariaDB** | `8.0+` | Uses standard ANSI SQL and ActiveRecord migrations. |
| **React** | `18.x`, `19.x` | Tested and verified on React 19.3.1. |
| **Next.js** | `14.x`, `15.x`, `16.x` | Tested with App Router (Turbopack) on Next.js 16.4.3. |
| **Spree Dashboard** | `@spree/dashboard >= 6.0.0` | Compatible with Developer Preview React admin dashboard. |
| **Spree SDK** | `@spree/sdk >= 6.0.0` | Store API V3 compatible. |

---

## Browser Support

- Chrome / Chromium: Last 2 versions
- Firefox: Last 2 versions
- Safari: Last 2 versions (macOS and iOS)
